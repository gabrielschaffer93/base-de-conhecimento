# Storage

## Overview

Media files (images and videos) are stored in Supabase Storage during the test phase. The app uses a `StorageAdapter` interface to allow future migration to Loft internal storage.

## Adapter pattern

```
src/lib/storage/
├── storageAdapter.ts          # Interface
├── supabaseStorageAdapter.ts  # Current implementation
└── loftStorageAdapter.ts      # Stub for future Loft infra
```

Switch implementation in `supabaseStorageAdapter.ts` export when migrating.

## Buckets

| Bucket | Types | Max size (suggested) | Public |
|--------|-------|----------------------|--------|
| `media-images` | jpg, png, webp, gif | 5 MB | Yes |
| `media-videos` | mp4, webm | 100 MB | Yes |

Create buckets in Supabase Dashboard → Storage → New bucket (public).

## Path convention

```
{year}/{month}/{uuid}-{sanitized-filename}
```

Example: `2025/06/a1b2c3d4-screenshot.png`

Generated by `buildStoragePath()` in `supabaseStorageAdapter.ts`.

## Database record

Each upload creates a row in `media_assets`:

- `storage_path` — path within bucket
- `public_url` — CDN/public URL
- `type` — derived from MIME type
- `uploaded_by` — profile ID

## Storage policies (Supabase)

Recommended policies:

```sql
-- Public read
CREATE POLICY "Public read images"
ON storage.objects FOR SELECT
USING (bucket_id = 'media-images');

CREATE POLICY "Public read videos"
ON storage.objects FOR SELECT
USING (bucket_id = 'media-videos');

-- Authenticated upload (editors)
CREATE POLICY "Editors upload images"
ON storage.objects FOR INSERT TO authenticated
WITH CHECK (
  bucket_id = 'media-images'
  AND public.has_role(ARRAY['super_admin', 'editor']::user_role[])
);

CREATE POLICY "Editors upload videos"
ON storage.objects FOR INSERT TO authenticated
WITH CHECK (
  bucket_id = 'media-videos'
  AND public.has_role(ARRAY['super_admin', 'editor']::user_role[])
);
```

## Migration to Loft storage

See [MIGRATION-LOFT.md](./MIGRATION-LOFT.md) for the full checklist.

Key steps:

1. Implement `LoftStorageAdapter`
2. Sync existing files from Supabase buckets to Loft CDN
3. Update `public_url` values in `media_assets`
4. Swap adapter in app config
